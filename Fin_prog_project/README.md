# Financial Monitoring Project

Рабочий каталог для нового проекта по мониторингу валют, нефти и золота с аналитикой через `codex exec` и доставкой уведомлений.

## Layout

- `docs/` - основная документация проекта, решения, планирование, исследования.
- `maps/` - короткие карты структуры проекта и навигационные файлы.
- `scripts/` - вспомогательные скрипты для bootstrap, проверок, локальных прогонов и прототипов.
- `data/` - локальные данные проекта: примеры, снимки рынка, экспортируемые артефакты.
- `config/` - шаблоны конфигурации и будущие runtime-настройки.
- `src/` - исходный код приложения.
- `tests/` - интеграционные и unit-тесты проекта.
- `logs/` - runtime-логи, browser traces, временные диагностические артефакты.
- `supplements/` - внешние справочные материалы, заметки по API, селекторам, prompt-шаблонам.

## Key Docs

- `docs/deep-research-report-fin-prog.md` - исходный deep research report.
- `docs/input_assumptions_v1.md` - зафиксированные входные допущения первой версии.
- `docs/mvp_stack_risks_plan.md` - стартовый разбор проекта на MVP, стек, риски и порядок реализации.
- `docs/bottlenecks_and_solutions.md` - перечень узких мест с конкретными решениями и мерами смягчения.
- `config/appsettings.example.json` - стартовый шаблон конфигурации.
- `config/evidence.schema.json` - machine-readable схема `evidence.json`.
- `maps/repo_map.md` - карта текущей структуры каталога.

## Rules

1. Каноничные проектные решения фиксируем в `docs/`, а не в чатах.
2. Один документ должен иметь одну роль: план, риск-реестр, карта, справочник.
3. Код и операционные артефакты не смешиваем с исследовательскими заметками.
4. Все новые рабочие скрипты и заготовки для автоматизации выносим в `scripts/`.
