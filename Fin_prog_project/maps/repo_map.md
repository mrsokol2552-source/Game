# Repo Map

## Top Level

- `README.md` - точка входа в проект и правила организации.
- `docs/` - каноничная документация, планы, риск-реестр, исследования.
- `maps/` - навигация по структуре проекта.
- `scripts/` - служебные скрипты и локальные инструменты.
- `data/` - данные, snapshots и экспортируемые артефакты.
- `config/` - шаблоны конфигурации.
- `src/` - код приложения.
- `tests/` - тестовый слой проекта.
- `logs/` - диагностические артефакты выполнения.
- `supplements/` - внешние справочные материалы.

## Data Layer

- `data/evidence/` - файлы `evidence.json` и связанные prompt-артефакты.
- `data/samples/` - примеры входных данных, моков и эталонных payload.
- `data/exports/` - экспортированные отчеты и промежуточные выгрузки.

## Working Rule

Новые файлы добавляем в тот слой, который владеет их ролью. Если роль спорная, сначала правим `README.md` или эту карту, а уже потом создаем файл.
