# Source

Основной исходный код приложения будет размещаться здесь.

Ожидаемые модули первой версии:

- `sources/` - сбор рыночных данных;
- `analytics/` - триггеры, волатильность, простые модели;
- `codex/` - prompt builder и runner для `codex exec`;
- `delivery/` - отправка сообщений;
- `storage/` - SQLite и файловые snapshot-артефакты;
- `logging/` - структурные логи и health-check.
